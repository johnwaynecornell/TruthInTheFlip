Note on RandomSD same-source controls:

The RandomSD NET2 run should be understood as a same-provider randomized anticipation control, not as a fully independent external predictor. The flip stream and the RandomSD anticipation stream are both divided from the same cryptographic randomness service, but the runner still preserves fair temporal order: the prior anticipation is scored against the current flip before the next anticipation state is computed. In that sense, RandomSD does not know the current answer before the guess is judged; it is another consumer of the same washed entropy source.

For NET2 this is acceptable and useful because cryptographic whitening is specifically designed to erase usable relation between draws. Any dependency is therefore micro-level — implementation order, buffering, thread scheduling, provider state — rather than a macro-level predictive channel. This makes RandomSD a good “same-source noise control,” while leaving room for a separate distinction in future QRNG tests between external-random controls, same-source controls, and serialized raw-entropy controls.

If it is ordinary variation, continued accumulation should eventually pull the measure back through 50%.

Quant.tkr completed its first matched-length physical entropy run at 8,903,400,000,000 flips, representing eighty-nine whole 100-billion-flip segments. The tracker was generated from direct Quantis source entropy without an additional whitening stage and used MetaGuess as its anticipation strategy.

The run is now archived as a mature experimental artifact alongside the established crypto3 baseline. Its length differs from crypto3 by only 14.4 billion flips, approximately 0.16 percent, while both reports contain the same number of complete default-scale segments. This provides a clean basis for comparing their completed-window distributions.

The completed record therefore supports the same scale-dependent description observed throughout its maturation: positive local structure was recurrent, while favorable long-scale occupation and settlement were uncommon.

The lifetime tracker stopped at a positive current endpoint, with anticipation TrueZ of +1.4111 in the active 10-billion window and +0.7017 in the active default window. These current values do not contradict the completed-window profile. They demonstrate again that a single ending position and the distribution of finite paths answer different questions.

The artifact also preserves several important local regimes. It includes strongly negative completed windows, a coherent default-scale positive segment that remained above chance throughout, large excursions that failed to settle, and later favorable intervals that softened but did not overturn the aggregate negative-settlement geometry.

When compared with crypto3 at the same eighty-nine-segment horizon, Quant.tkr shares the broader pattern of positive excursion combined with negative average settlement. The numerical profiles differ, particularly in default-scale excursion, time above baseline, and short-window settlement, but one run from each source is not sufficient to classify those differences as persistent source effects.

Quant.tkr is therefore committed as the first mature direct source-entropy MetaGuess artifact. It establishes a physical-entropy baseline for future comparisons involving conditioned Quantis RNG output and alternate anticipation strategies.

The previously announced next experiment is direct Quantis RNG mode with MetaGuess, preserving the anticipation strategy while changing the hardware output mode. This remains the cleanest immediate controlled comparison. The consistently low default-scale settlement and mean values have also made a future direct source-entropy AntiMetaGuess run especially compelling. That later run will test the complementary anticipation principle on fresh physical entropy; it will not be an exact inversion or replay of Quant.tkr.
